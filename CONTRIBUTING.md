# Contributing to Torafirma Skill Router

Thanks for your interest in this project.

## Issues

Bug reports and feature requests are welcome. When you open an issue, please describe what you expected to happen and what actually happened, include steps to reproduce with OS or build details where relevant, and attach any relevant logs or output.

## Pull requests

This project does not accept external pull requests at this time. Please do not submit PRs, as they will be closed without review. If you have a fix or feature in mind, open an issue describing it instead so it can be considered and potentially implemented upstream.

## Security

Please do not open public issues for security vulnerabilities; contact the maintainer directly instead.
